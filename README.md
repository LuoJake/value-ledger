# 衡石 · A 股价值投资研究台

面向长期价值投资者的静态研究工具。主分支只覆盖中国 A 股；原来的美股 SEC 版本保存在 `us-market-v1` 分支。

线上地址：https://luojake.github.io/value-ledger/

## 数据来源与可信度边界

| 层级 | 来源 | 用途与边界 |
| --- | --- | --- |
| 一级：法定披露 | 上海证券交易所、深圳证券交易所、北京证券交易所、巨潮资讯 | 年报、公告原文，是最终核验依据 |
| 一级：宏观原始发布 | 国家统计局、中国人民银行 | GDP、CPI、PMI、货币供应量的最终核验依据 |
| 二级：结构化数据 | 东方财富数据接口 | 多年财务指标、行情和宏观数据的整理层，便于计算与展示 |
| 三级：规则推演 | 本站透明计算规则 | 财报体检、成长分析、投资者方法论视角和宏观传导解释 |

结构化财务数据会自动尝试匹配同年度的官方年报 PDF，并显示匹配状态。未匹配时必须人工复核，不能仅凭图表决策。行情允许延迟或缺失，也不用于交易。本站不会用媒体文章替代法定公告，不会为缺失数据生成猜测值。

## 自选股

- 可以直接输入任意 6 位 A 股代码，支持沪市、深市和北交所。
- 每只股票都可以单独删除，也可以清空整个自选列表。
- 自选列表、研究笔记和检查项只保存在当前浏览器，不会上传。
- 仓库预配置股票由定时任务抓取财务数据并匹配官方公告。
- 浏览器临时新增的股票会读取结构化财务数据，并在以后打开网页时尝试刷新；受浏览器跨域限制，暂不自动抓取其官方公告，页面会明确标为“未核验”并提供官方查询入口。

如需让某只股票获得定时更新和官方年报自动匹配，请编辑 `public/data/watchlist.json`，再运行抓取脚本。深市公司的 `orgId` 可从巨潮资讯官方股票列表查询。

## 财报与成长分析

页面会基于最多六个完整年度的数据自动计算：

- 收入和归母净利润同比变化、复合增长率及二者背离。
- 最近三年经营现金流对利润的覆盖情况。
- ROE 的平均水平、最低值和最新变化。
- 资产负债率、毛利率趋势和需要进一步回答的问题。
- 成长质量、增长持续性及估值和增长是否大致匹配。
- 风险类公告标题，仅用于提示回到原文核验。

这些结论是透明、可复算的规则分析，不是大模型阅读年报全文。它不能替代对审计意见、会计附注、关联交易、商誉、管理层讨论和公司治理的人工阅读。

## 投资者方法论视角

财报体检页会分别用格雷厄姆、巴菲特、段永平和成长股研究框架进行条件式推演，例如安全边际、资本回报、现金转化、商业模式和增长质量。

这些内容仅根据公开方法论和当前结构化数据生成，不是这些投资者本人对该公司的观点，更不是对当前价格的真实买卖建议。缺少竞争优势、管理层文化、行业空间等事实时，页面会明确提示“仍需核验”，而不会补造结论。

## 宏观观察

宏观页展示 GDP、CPI、制造业 PMI、M1 和 M2，并把内容分成三层：

- 事实：最新公布值和统计期。
- 原理：指标变化如何通过需求、价格、库存、融资等路径传导。
- 推断：对消费、制造、成长企业以及银行保险研究可能意味着什么。

宏观分析用于建立企业研究背景，不预测短期指数涨跌。结构化数据由东方财富整理，最终应回到国家统计局和中国人民银行原始发布核验。

## 本地运行

```powershell
npm.cmd install
python scripts/fetch_a_share_data.py
npm.cmd run dev
```

## 自动更新与发布

- `update-data.yml` 每两小时抓取财务、行情、官方披露和宏观数据，并在数据变化时提交。
- `deploy.yml` 在主分支推送或数据更新成功后发布 GitHub Pages。
- 美股旧版保留在 `us-market-v1` 分支，不参与当前 A 股站点发布。

本站只用于研究，不构成投资建议。重大投资决定应回到交易所、巨潮资讯、国家统计局或中国人民银行的原始文件，并阅读审计意见、附注、风险因素与管理层讨论。
